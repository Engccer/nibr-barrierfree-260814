# 내가 만난 배리어프리 교육과 전시

국립생물자원관 교육강사 워크숍 강연 슬라이드덱입니다.

- 일시: 2026년 8월 14일(금) 11:00~12:00
- 장소: 나인트리 프리미어 로카우스 호텔 서울 용산 9층 안중근실
- 주최: 국립생물자원관 생물다양성교육과
- 발표: 김헌용 (신명중학교 영어 교사, 함께하는장애인교원노동조합 위원장)

배포본: https://engccer.github.io/nibr-barrierfree-260814/

## 내용

시각장애인 교사가 전시기관에서 받아 본 해설이 어떻게 달랐는지를 뮤지엄 산, 암스테르담 반 고흐 미술관, 국립중앙박물관 세 곳의 사례로 짚습니다. 이어 촉각 자료가 하는 일을 건축 모형과 경기장 소장품과 감각전시실 「공간_사이」로 살펴보고, 같은 원칙을 교실에 적용해 만든 학습자료와 학생 155명의 평가를 소개합니다. 마지막으로 생물다양성교실에 그대로 적용할 수 있는 다섯 가지를 제안합니다.

## 조작

| 키 | 동작 |
|---|---|
| 오른쪽 화살표, PageDown | 다음 항목이나 다음 장 |
| 왼쪽 화살표, PageUp, Backspace | 이전 |
| Home, End | 처음, 마지막 |

터치 화면에서는 좌우로 밉니다. 상단의 「문서 모드로 보기」를 누르면 전체가 한 페이지로 펼쳐집니다.

## 접근성

시각장애인 발표자가 직접 쓰는 덱이라 다음을 지켰습니다.

- 항목이 하나 등장할 때와 다음 장으로 넘어갈 때의 효과음을 다르게 두어 진행 상태를 귀로 구분합니다
- 장을 넘기면 포커스가 그 장의 첫 줄로 이동하고, 항목이 등장하면 그 항목으로 이동합니다
- 미등장 항목은 `visibility:hidden`으로 감춰 화면 낭독기가 미리 읽지 않습니다
- 키워드는 세로로 세운 목록이라 한 번에 하나씩 읽힙니다
- 랜드마크와 불필요한 ARIA를 두지 않았습니다

## 사진 출처

「공간_사이」 사진 두 장은 뉴시스 보도 사진이며 해당 슬라이드에 출처를 표기했습니다. 경기장 소장품 슬라이드의 이미지는 현장 사진을 대신해 생성한 것이며 슬라이드에 그렇게 밝혔습니다. 나머지 사진과 영상은 발표자 본인의 것입니다.

`lecture-deck` 스킬의 템플릿과 검증 스크립트를 씁니다. 슬라이드 문안이 확정된 원고에서 왔는지, HTML 구조와 접근성이 기준을 지키는지 기계로 대조합니다.
